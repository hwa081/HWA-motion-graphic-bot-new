# reference/ - videos the bot learns from

Put your best example videos here (.mp4 .mov .webm .mkv .m4v .avi .gif).
Then open the Studio page -> Tools -> "Learn from reference videos" -> Learn.
The bot looks at every video once and remembers its style (colours, pace, cuts, motion, layout).

Tips:
- Short clips (10-60 seconds) work best. GitHub does not accept a single file over 100 MB.
- Needs a working Gemini key (it looks at the pictures).
- A video that was already learned is skipped next time.
