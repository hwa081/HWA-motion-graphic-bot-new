PUT YOUR OWN SOUND FILES HERE (wav / mp3 / ogg / m4a / flac).

The bot's styles "premium" and "viral" use the files in this folder instead of the built-in synthetic sounds.
The FILE NAME decides where a sound is used (any number of files per kind; one is picked at random, always the same one for the same video):

  whoosh_1.wav, swoosh.mp3, transition air.wav     -> whoosh (headline blur/wipe/pop, scene change)
  slide.wav, swipe.wav                             -> slide
  typing key.wav, keyboard 2.wav                   -> a letter / word typing in
  tap.wav, tick.wav                                -> small taps
  pop.wav, bubble.wav                              -> popups (cards, chips, icons)
  chime.wav, success.wav, ding.wav                 -> check mark / end of counter
  ping.wav, glass.wav, bell.wav                    -> pings
  sparkle.wav, shimmer.wav, magic.wav              -> closing bloom
  riser.wav, build.wav, swell.wav                  -> build-up before a cut
  thud.wav, hit.wav, impact.wav, boom.wav, punch   -> big hero headline / cut
  shutter.wav, camera.wav, multiple shutter.wav    -> images (single click / fast burst)
  gravel.wav, dark hit.wav, bass drop.wav          -> heavy hits
  slice.wav, gone fast.wav, tape stop.wav, rewind.wav

Only put sounds here that you are allowed to use (your own, free-licence, or a pack you got legally from its creator).
Everything you do not provide keeps the built-in sound. Env SFX_PACK=<folder> can point somewhere else.

INCLUDED NOW (cut from the "Premium SFX" sample video, creator says free to use): riser_1 (build-up), whoosh_1, pop_1, thud_1, drop_1, typing_6 (21 key hits).
TYPING: when a typing file exists (premium style), text that types in (letters / chars / words reveal) is re-timed so EVERY letter appears exactly on a key hit of the clip, and the sound plays those hits. Longer text repeats the clip's cadence.
Delete a file here to go back to the built-in sound for that kind.
